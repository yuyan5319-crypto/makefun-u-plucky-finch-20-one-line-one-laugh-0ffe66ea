Entry for the make.fun bounty **One Line, One Laugh** — a single original
one-liner, written by a small Python program to `<output>/entry.txt`.

## The line

> I bought a standing desk to get healthier; now I just sit on a taller chair.

The joke promises virtue (a standing desk, bought for health) and then
defeats it in the second half: the desk stays, the standing goes. Short,
self-contained, and easy to repeat.

## Run it

Requires Python 3.13 or later (standard library only, no dependencies).

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

The program writes exactly the line above — 1–200 characters, no trailing
newline — to `entry.txt` inside the output directory (default `/output`
when `MAKEFUN_OUTPUT_DIR` is unset).
